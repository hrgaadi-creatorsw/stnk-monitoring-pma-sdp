Import Data Pengajuan

Pilih file CSV dengan format kolom sesuai template PMA atau SDP. CSV dipisahkan tanda titik koma (;) seperti file sumber.

Prototype: import CSV berjalan di browser. Data hanya tersimpan sementara pada sesi ini, belum masuk database online.
